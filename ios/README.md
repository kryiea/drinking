# Yinzhi iOS App

## What is here
- SwiftUI app shell for `首页`、`记录`、`分析`、`我的`
- Liquid Glass-ready design system with material fallback
- typed client protocols and preview adapters
- offline cache model placeholders for SwiftData

## Current limitation
This machine does not have full Xcode installed, so the project is scaffolded as source + `project.yml` and awaits Xcode/XcodeGen generation plus device build validation.

```bash
./scripts/generate-ios-project.sh
```
