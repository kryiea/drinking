# ADR-0001: 前后端分离与 iOS Liquid Glass 首版架构

## 状态
Accepted

## 背景
项目需要由 AI 长期主导开发与维护，且产品要求明确包含后端能力、跨设备数据真源、可持续文档系统和 iOS 玻璃视觉体验。

## 决策
- 采用 FastAPI 模块化单体作为首版后端。
- 采用 SwiftUI 作为 iOS 客户端 UI 技术栈。
- 服务端作为业务真源，本地 SwiftData 作为离线缓存。
- 推荐系统首版采用确定性规则引擎与模板化解释，不做开放对话。
- UI 主视觉按 iOS 26+ Liquid Glass 设计，对旧系统提供材料 fallback。
- 采用 OpenSpec + 仓库内长期文档双轨制管理需求和实现。

## 结果
- 接口、领域模型、文档边界更清晰，便于 AI 增量接手。
- 首版开发速度优于微服务，但保留未来拆分空间。
- 在没有完整 Xcode 的环境中仍能推进 Swift 源码、共享逻辑和文档建设。

## 代价
- 当前环境无法完成真实 iOS 编译验证。
- 后端首版仍需从开发适配器升级到真实数据库和缓存设施。
- 需要更严格维护文档与接口同步纪律。
