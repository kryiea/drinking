# 饮知 v1 范围说明

## 核心价值
帮助用户在喝咖啡、奶茶、茶饮、功能饮料、碳酸饮料和果汁等日常场景中，记录饮品摄入、理解健康影响，并获得可解释的个性化建议。

## 用户路径
1. 完成 onboarding，填写基础档案与健康目标。
2. 通过目录搜索、最近记录或自定义模板记录一杯饮品。
3. 在首页看到今日摄入状态、阈值进度与即时建议。
4. 在分析页理解趋势、结构和建议的科学解释。
5. 在我的页面管理账号、导出、隐私与设备权限。

## 第一版包含
- Apple 登录接后端账号
- 饮品目录搜索与手动记录
- 品牌化饮品定义与风味提示
- 手冲/咖啡机参数计算入口
- 最近记录与收藏模板
- 每日摄入聚合
- 可解释建议卡片
- 离线缓存与恢复同步
- CSV/PDF 导出任务接口
- 开发者 support 平台与建议规则/反馈快照

## 当前 UI 方向
- 首页减少说明性长文案，优先展示今日结论、关键指标和可操作建议。
- 记录页强化品牌识别、冲泡方式和快速录入，不把所有信息挤在首页首屏。
- 支持平台面向开发者，优先服务规则调试、反馈复核、LLM 联调和数据可视化，而不是做通用运营后台。

## 第一版不包含
- 社区、专家咨询、企业版、订阅付费
- 聊天式 AI
- 条码、语音、图像识别
- 开放平台 API
