# Logging Core Spec

## Requirements
- The app must optimize the `记录` experience for coffee-first daily intake logging rather than AI-driven recommendation browsing.
- The log screen must present quick logging actions before full catalog exploration.
- The catalog must ship with mainstream coffee and milk-tea brands plus a clearly separated user-defined drinks section.
- The app must support structured voice input for beverage logging with an explicit confirmation step.
- If voice or image parsing is incomplete, the user must be routed into a recoverable manual search path rather than a dead end.
- Local-first persistence must preserve brand and preparation-method metadata so recent logs and analysis remain brand-aware after offline saves.
