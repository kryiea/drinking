# Logging UX Spec

## Requirements
- The app must expose fast record actions before full catalog browsing on the log screen.
- The app must support a local image-recognition assist flow that suggests branded drink candidates from OCR text.
- When recognition cannot find a confident candidate, the user must still be guided into a recoverable manual search path.
- Quick entry UX must not remove brand filters, recent entries, or Brew Lab; it only changes priority and layout.
