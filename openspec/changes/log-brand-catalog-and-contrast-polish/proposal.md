# Proposal

## Why
- 首页时间图的睡眠线在浅色模式下对比度不足，关键状态信息不够稳定。
- 记录页品牌筛选仍然是字母圆标和偏重文字的 row，没有真正形成“看 logo 就点”的快速记录体验。
- 当前预设目录缺少一批中国用户高频品牌与代表饮品，难以支撑记录页的主场景。
- 暗色模式下若干胶囊、标签与卡片层级仍偏灰白拼贴，质感不够统一。

## What Changes
- 提升首页“睡眠线”及其标签在浅色 / 深色模式下的可读性。
- 重构记录页品牌 rail 和饮品 row，改为更小的品牌 logo、去掉冗余文字、压缩次要信息。
- 预设并排序中国高频品牌与代表饮品：`瑞幸`、`星巴克`、`库迪`、`喜茶`、`霸王茶姬`、`一点点`。
- 将品牌展示统一成小 logo 风格，并在品牌 rail、记录 row、最近记录中复用。
- 继续优化暗色模式下的背景、表面、标签和选中态表现。

## Expected Outcome
- 首页关键阈值和时间信息在两套外观下都稳定可读。
- 记录页更像“logo 选择器 + 极简目录”，用户扫一眼就能找到品牌并记录。
- 新用户打开 App 就能看到主流咖啡 / 奶茶品牌的代表饮品，不需要先自行建设目录。
