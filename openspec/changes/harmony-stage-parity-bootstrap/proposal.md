# Proposal

## Why
- 用户已经明确要求项目进入 HarmonyOS 适配阶段，并希望体验尽量保持与当前 iOS 版本一致。
- 仓库虽然已建立 `harmony/` 根目录，但还没有真正的 HarmonyOS 工程、环境脚本和页面实现。
- 如果现在不把鸿蒙端按正式工程方式拉起来，后续适配会继续停留在“规划存在、代码缺席”的状态。

## What Changes
- 在 `harmony/` 下建立基于 `Stage + ArkTS` 的 HarmonyOS 工程骨架。
- 实现 HarmonyOS 端的四个一级页面：`首页`、`记录`、`分析`、`我的`。
- 迁移本地优先的核心领域能力：
  - 饮品 starter pack
  - 咖啡因时间衰减计算
  - 记录一杯与最近记录
  - 咖啡因计算器
  - 入睡时间 / 代谢设置
- 新增 Harmony CLI 环境脚本与文档，记录本机命令行工具安装路径和已知阻塞。

## Non-Goals
- 本次不承诺真机或模拟器已完成最终构建验证。
- 本次不接完 HarmonyOS 相机、语音、相册权限能力。
- 本次不让 HarmonyOS 端替代 iOS 成为当前主交付端。
